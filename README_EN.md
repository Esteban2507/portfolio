## 🎨 Design

A **dark-blue glassmorphism** style: animated gradient background, semi-transparent blurred panels, `Outfit` (headings) + `Inter` (body) typography, and a single brand accent color (sky-blue). Within the Projects section, category accents (purple for AI, yellow for Data) visually separate both blocks.

## 🧪 Quality and maintenance

- Semantic HTML with internal navigation and a skip link.
- Responsive layout with glassmorphism cards, 3D tilt effect and magnetic buttons.
- AI apps with no build step: React 18 + Babel Standalone loaded directly from CDN.
- Basic SEO, JSON-LD, Open Graph and Twitter Cards on the home page.
- `prefers-reduced-motion` support for motion-sensitive visitors.
- GitHub Actions workflow (`.htmlhintrc`) validating HTML syntax on every push.
