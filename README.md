## 🚀 Sobre mí

¡Hola! Soy **Esteban**, un apasionado por la eficiencia y la inteligencia de negocios. Mi objetivo es simple: **automatizar lo repetitivo para enfocarnos en lo estratégico**.

Me especializo en conectar puntos: cruzar reportes contables, visualizar tendencias de ventas y crear herramientas que ahorran horas de trabajo manual. Actualmente estoy dando el salto hacia la **IA aplicada**, integrando la API de Claude (Anthropic) en herramientas reales de análisis de datos y generación de reportes ejecutivos.

## 🎨 Diseño

Estilo **glassmorphism dark-blue**: fondo con gradiente animado, paneles semi-transparentes con blur, tipografía `Outfit` (títulos) + `Inter` (cuerpo), y un acento de marca único (sky-blue). Dentro de Proyectos, los acentos de categoría (morado para IA, amarillo para Datos) diferencian visualmente ambos bloques.

---

## 🧪 Calidad y mantenimiento

- HTML semántico con navegación interna y enlace de salto al contenido.
- Diseño responsive con cards glassmorphism, efecto tilt 3D y botones magnéticos.
- Apps de IA sin build step: React 18 + Babel Standalone directamente desde CDN.
- SEO básico, JSON-LD, Open Graph y Twitter Cards en la home.
- Soporte para `prefers-reduced-motion` en usuarios sensibles al movimiento.
- Workflow de GitHub Actions (`.htmlhintrc`) que valida la sintaxis HTML en cada push.
