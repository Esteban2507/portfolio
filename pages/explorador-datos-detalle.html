Data Explorer with AI

A Spanish-language demo for asking questions about tabular data and turning relevant answers into charts.

Problem

Exploring a spreadsheet can require formulas or code just to answer an initial question.

Solution

The app loads CSV or Excel files and lets you ask a question in Spanish. It displays the model's response and, where relevant, renders a bar, line or pie chart.

Technology

  • React
  • JavaScript
  • Chart.js
  • Papa Parse
  • SheetJS
  • AI provider APIs

Result

The prototype demonstrates an interactive first pass through sample data with both conversational and chart output.

Try the demo

The demo is in Spanish and requires an API key from your chosen provider. The demo sends the question and data it uses to the AI provider you select. Use synthetic or public examples.
