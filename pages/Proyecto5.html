Invoice Control Dashboard

A dashboard that checks whether supplier invoices appear correctly across two sources.

Problem

Invoices recorded in two sources had to be checked before payment so missing records or discrepancies could be reviewed.

Solution

I modeled both sources in Power BI and wrote DAX measures to compare the supplier, invoice reference, currency and amount. Visual indicators explain which checks need attention.

Technology

  • Power BI
  • DAX
  • Data modeling

Result

The dashboard distinguishes matches from discrepancies. It offers access to the source record when the invoice is correctly registered.
