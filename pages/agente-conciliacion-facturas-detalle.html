Invoice Reconciliation Agent

A conversational agent that coordinates report preparation and invoice checks, then organizes the results for review.

Problem

Invoice reconciliation required preparing reports from different sources, comparing key fields and tracking exceptions. Each task was repeatable, but moving between files made the overall workflow harder to follow.

Solution

I designed a Copilot Studio agent that interprets a request and calls a Power Automate flow. Office Scripts prepare the input and apply defined comparisons. The flow records the outcome in SharePoint and Power BI shows the results for follow-up.

Technology

  • Microsoft Copilot Studio
  • Power Automate
  • Office Scripts
  • SharePoint
  • Power BI

Result

The workflow distinguishes matching records from cases that need attention. The agent reports the run outcome and the person responsible retains the payment approval decision.

Impact

The team can apply the same comparison criteria across runs and find exceptions in one place.
