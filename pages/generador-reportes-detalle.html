Descripción del Proyecto

Aplicación que convierte datos crudos (bullets, tablas, texto de un mail) en un reporte ejecutivo estructurado. El usuario elige el tipo de reporte (Ventas, Financiero, Operaciones, RRHH, Proyecto o General), el tono (Ejecutivo, Formal o Narrativo) y la audiencia (CEO, Gerencia, Equipo o Cliente), y la IA redacta un documento con ocho secciones: título, resumen, métricas con tendencias, hallazgos, análisis, riesgos, recomendaciones y conclusión. El resultado se puede copiar como texto plano para pegar en Word o en un mail.

Herramientas Utilizadas

  • React 18 (Babel Standalone)
  • Claude API (claude-sonnet-4-6)

Impacto

Reduce el tiempo de redacción de reportes ejecutivos de horas a minutos, manteniendo un formato claro y consistente, y adaptando el tono y el nivel de detalle según quién vaya a leerlo.
