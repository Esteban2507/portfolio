Data & Analytics Project with a fictional dataset

Sales Analysis with Python

An analysis that compares sales performance across products, months and regions using fictional company data.

Problem

Raw sales exports make it hard to see how revenue varies by product, month and region.

Solution

I prepared the CSV files with pandas and built charts in Matplotlib and Seaborn to compare regional performance and show trends over time.

Technology

  • Python
  • pandas
  • Matplotlib
  • Seaborn

Result

The analysis demonstrates how to identify higher-performing products and seasonal or regional patterns in a fictional dataset.
