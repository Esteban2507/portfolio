Translation API

A lightweight web interface for selecting languages and translating text through a Python API.

Problem

The project explores how to make translation accessible from a simple web form.

Solution

I built a Flask application that accepts text and language options, delegates translation to Google Translate through the googletrans library, and returns the translated text to the interface.

Technology

  • Python
  • Flask
  • googletrans
  • HTML
  • CSS

Result

The app supports translation between languages available through the library and runs locally with Flask.
