Control de Pagos

Descripción del Proyecto

Este dashboard fue creado en Power BI para comparar las facturas ingresadas en distintos sistemas contables. El objetivo principal es asegurar que los pagos se realicen correctamente, evitando duplicidades o montos erróneos.

Herramientas Utilizadas

  • Power BI
  • Excel (fuentes de datos)
  • Power Query
  • DAX

Impacto

Gracias a este control automatizado, se logró reducir en un 90% los errores en el proceso de validación de facturas, optimizando significativamente el tiempo del equipo contable.
