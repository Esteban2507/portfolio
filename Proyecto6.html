Resumen del Proyecto

Este proyecto es una API Traductora desarrollada en Python con Flask, utilizando la librería googletrans. Permite traducir texto de un idioma a otro mediante una interfaz web sencilla y funcional.

Características principales

  • Traducción entre múltiples idiomas soportados por Google Translate.
  • Interfaz web amigable desarrollada en HTML y CSS.
  • Despliegue local con Flask (http://127.0.0.1:5000).
  • Posibilidad de ampliarse y personalizarse fácilmente.

Tecnologías utilizadas

Python Flask Googletrans HTML CSS
